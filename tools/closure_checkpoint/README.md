# HeartGold Silicon — Native Link Closure Checkpoint

**Verified frontier: 167 unresolved ARM64 linker identities.**

The `staged_sources/` directory preserves ten source artifacts from verified staging experiments. They are not yet integrated into the default build pipeline.

The BSS ledger records 64 actual original allocations across five Wi-Fi owners, including 38 missing linker identities. Public declarations without local storage are recorded separately.

Original four-byte slots must not automatically become native pointer definitions. Each allocation needs source-derived type, size, ownership, and consumer-ABI validation.

Generated native objects and local linker inputs remain under build/ and are not part of this checkpoint.
