# Museum

This is **not** an archive of old scripts, staging code, progress reports, or
failed experiments. Git history already preserves those.

Admission is exceptional: a historically significant verified achievement or
original primary record, with provenance and technical evidence that would
otherwise be lost. Age, novelty of a prototype, and prior usefulness are not
sufficient. No active build or test can depend on this directory.

There are currently no admitted artifacts. Historical linker experiments and
assembly prototypes remain available in Git history; their working-tree copies
were removed during build-system hygiene.
